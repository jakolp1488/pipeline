Pipeline

Pipeline is a YouTube video processing and TikTok publishing tool. Download and process videos automatically, then publish them to your TikTok account through the official TikTok API.

Connect TikTok

OAuth endpoint is not configured yet. Edit config.js and set OAUTH_URL to your deployed Cloudflare Worker URL (see TIKTOK_SETUP.md in the repository).

/ what it does

Video processing

Pipeline takes source videos and processes them automatically: subtitle rendering, font styling and format conversion.

TikTok publishing

Finished videos are published to TikTok with the official Content Posting API — Direct Post — after you review and confirm each post.

TikTok connection

Account connection uses TikTok OAuth (Login Kit). You grant Pipeline permission to post on your behalf, and you can revoke it at any time.

Your control

Nothing is published without your explicit action. Titles, privacy level and interaction settings are chosen by you before every post.

/ how the tiktok integration works
  1. You click Connect TikTok and are redirected to TikTok's official authorization page.
  2. You sign in to TikTok and grant Pipeline the requested permissions.
  3. Pipeline's OAuth backend receives the authorization code and stores access and refresh tokens securely on the server side.
  4. When you publish a video, Pipeline sends it to TikTok's official upload endpoint and tracks the publish status until it completes.
/ tiktok data

Pipeline uses the official TikTok for Developers APIs: Login Kit (OAuth) and the Content Posting API (Direct Post). It reads only the account data required for posting: your TikTok profile information (avatar, username, nickname) and the posting settings of your account. Read our Privacy Policy for details.
